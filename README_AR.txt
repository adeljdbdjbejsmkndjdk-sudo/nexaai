NexaAI — نسخة جاهزة للنشر والربط

ماذا تحتوي الحزمة؟
- index.html: واجهة عربية وإنجليزية متوافقة مع الهاتف.
- server.js: خادم آمن نسبيًا يستدعي Gemini من جهة الخادم، وليس من المتصفح.
- package.json: المكتبات وأمر التشغيل.
- render.yaml: إعداد نشر أولي لخدمة Node على Render.
- .env.example: مثال لمتغير المفتاح. لا تضع المفتاح في ملفات الواجهة.

تشغيل محلي (على كمبيوتر):
1) ثبّت Node.js.
2) افتح مجلد المشروع في الطرفية.
3) نفّذ: npm install
4) انسخ .env.example إلى ملف باسم .env.
5) افتح .env وضع مفتاح Gemini مكان النص التجريبي.
6) نفّذ: npm start
7) افتح http://localhost:3000

النشر:
1) يلزم رفع ملفات المجلد إلى مستودع GitHub تملكه.
2) اربط المستودع بخدمة استضافة تدعم Node.js (ملف render.yaml مرفق كبداية).
3) أضف GEMINI_API_KEY كمتغير سري في إعدادات الاستضافة، ولا تضعه في كود الواجهة.
4) انشر الخدمة واختبر أدوات الموقع.

حدود مهمة:
- الحزمة لا تنشئ حساب استضافة أو مستودع GitHub نيابةً عنك.
- لا يوجد حتى الآن تسجيل مستخدمين أو اشتراكات أو تحصيل أموال.
- الدفع بالجنيه المصري والدولار يحتاج مزود دفع وحساب تاجر ومراجعة شروطه.
- الخطة المجانية للاستضافة أو الذكاء الاصطناعي قد تتغير أو تكون لها حدود؛ تحقق من الأسعار وحدود الاستخدام قبل الإطلاق.
- لا تشارك مفتاح API في المحادثة أو مع أي شخص.
